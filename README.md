# 🏄‍♂️ Tikehau Surf Shop - Site de Apresentação

Um site moderno e responsivo para apresentação da loja de surf Tikehau, desenvolvido com HTML5, CSS3, JavaScript e Bootstrap 5.

## ✨ Características

- **Design Responsivo**: Adapta-se perfeitamente a todos os dispositivos
- **Paleta de Cores Tropical**: Azul turquesa, areia e verde-água
- **Navegação Suave**: Scroll suave entre seções
- **Carrossel Interativo**: Imagens hero com transições animadas
- **Galeria de Fotos**: Modal para visualização ampliada
- **Formulário de Contato**: Validação e feedback visual
- **Mapa Interativo**: Localização da loja integrada
- **Animações**: Efeitos visuais modernos e suaves

## 🚀 Como Usar

1. **Abrir o Site**: Simplesmente abra o arquivo `indexC.html` no seu navegador
2. **Navegação**: Use o menu superior para navegar entre as seções
3. **Carrossel**: Clique nas setas ou indicadores para navegar pelas imagens
4. **Galeria**: Clique em qualquer foto para ampliá-la
5. **Contato**: Preencha o formulário para entrar em contato

## 📁 Estrutura de Arquivos

```
Projetos/

├── styles.css           # Estilos personalizados
```

### 1. **Home (Hero)**

## 🎯 Funcionalidades JavaScript

- **Scroll Spy**: Destaque da seção ativa no menu
- **Smooth Scroll**: Navegação suave entre seções
- **Validação de Formulário**: Validação de email e campos obrigatórios
- **Máscara de Telefone**: Formatação automática do número
- **Contador de Caracteres**: Para o campo de mensagem
- **Lazy Loading**: Carregamento otimizado de imagens
- **Botão Voltar ao Topo**: Navegação rápida
- **Animações ao Scroll**: Efeitos visuais ao rolar a página

## 📱 Responsividade

O site é totalmente responsivo e se adapta a:
- **Desktop**: Layout completo com 3 colunas
- **Tablet**: Layout adaptado com 2 colunas
- **Mobile**: Layout em coluna única otimizado

## 🔧 Personalização

Para personalizar o site:

1. **Imagens**: Substitua as URLs das imagens do Unsplash pelas suas próprias
2. **Texto**: Edite o conteúdo nas seções correspondentes
3. **Cores**: Modifique as variáveis CSS no arquivo `styles.css`
4. **Informações de Contato**: Atualize telefone, email e endereço
5. **Mapa**: Substitua o iframe do Google Maps pela localização real
