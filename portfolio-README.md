# 🚀 Portfólio Profissional - Isaque Souza de Mesquita

Um portfólio moderno e minimalista desenvolvido para atrair clientes freelancers, com foco em desenvolvimento web full-stack.

## ✨ Características

- **Design Minimalista**: Interface limpa e profissional
- **Totalmente Responsivo**: Adapta-se a todos os dispositivos
- **Animações Suaves**: Efeitos visuais modernos com AOS
- **SEO Otimizado**: Configurado para aparecer no Google
- **Performance**: Carregamento rápido e otimizado
- **Foco em Freelancer**: Estruturado para atrair clientes

## 🎯 Objetivo

Este portfólio foi criado especificamente para:
- Atrair 3-4 clientes freelancers por mês
- Mostrar habilidades em desenvolvimento web
- Destacar projetos futuros e passados
- Facilitar contato direto com clientes
- Estabelecer credibilidade profissional
